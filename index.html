My role

How I approached it
  • Prepared and preprocessed the gesture data, then trained and evaluated the models.

  • Shaped a dual-mode experience so each group gets what it needs.
  • Worked with engineers to make performance and reliability the core success metrics.
What shipped
A real-time gesture recognition system for emergency assistance, measured against detection accuracy and response speed benchmarks.
